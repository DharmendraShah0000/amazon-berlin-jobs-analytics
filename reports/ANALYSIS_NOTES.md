# Analysis notes

Amazon's Berlin location page describes Merchant Services, AWS technology teams and corporate support functions. Public Amazon.jobs search results showed a dated listing-count snapshot (see `official_source_snapshot.csv`).

The synthetic sample cannot support claims about actual Amazon hiring volume, skill demand, salaries or vacancy trends. For empirical analysis, collect a permitted dated dataset of public job ads, preserve requisition IDs/source URLs/capture timestamps, deduplicate records and document missing values before calculating trends.
